# Form CRM

Простая одностраничная CRM для добавления и сопровождения лидов. Данные
сохраняются в `localStorage` текущего браузера и остаются после обновления
страницы.

## Возможности

- поля имени, телефона, источника, ответственного и этапа сделки;
- отметка «Запрошено ТЗ»;
- понятная проверка обязательных полей;
- карточки со всеми введёнными данными;
- сохранение лидов после перезагрузки страницы;
- перевод сделки на следующий этап;
- адаптивный интерфейс для компьютера и телефона.

## Локальный запуск

```bash
npm ci
npm run dev
```

Для полной проверки:

```bash
npm run check
```

## Где находится логика

- Интерфейс и обработчики формы: `app/components/lead-crm.tsx`.
- Правила проверки и переходов между этапами: `app/lib/leads.ts`.
- Чтение и сохранение данных: `app/lib/lead-storage.ts`.
- Внешний вид: `app/globals.css`.
- Пользовательские сценарии: `tests/e2e/crm.spec.ts`.

## Демонстрационный сценарий

1. Нажать «Сохранить лида» с пустыми именем и телефоном и показать ошибки.
2. Заполнить форму и сохранить нового лида.
3. Обновить страницу и показать сохранённую карточку.
4. Нажать «Следующий этап», ещё раз обновить страницу и показать новый этап.

## Использование нейросети

Codex подготовил структуру репозитория, исходный код, стили, тесты, CI и
документацию. После генерации отдельно проверяются обязательные поля, создание
карточки, восстановление данных после обновления и сохранение изменённого этапа.

Решение намеренно не содержит авторизацию, серверную базу, телефонию и
интеграции с мессенджерами.
